# 三项目融合路线图

## 文档定位

本文档用于说明 TradingAgents、FinceptTerminal、MiroFish 三个项目在 A股智研台中的融合定位，以及哪些内容只学思想、哪些未来可由本项目自行实现。

## 三个项目的融合定位

### TradingAgents：AI 投研大脑

其主要启发位置在于：

- 多角色研究结构
- 看多 / 看空辩论
- 风控审查
- 结构化研究输出
- 决策记忆思路

它回答的是：研究流程怎么拆，研究结论怎么结构化。

### FinceptTerminal：金融终端外壳

其主要启发位置在于：

- 金融终端产品形态
- 模块化工作台
- 页面层 / 服务层解耦
- DataHub 思路
- 报告中心、风控中心、工作区设计

它回答的是：产品平台怎么搭，终端怎么组织。

### MiroFish：情景推演沙盒

其主要启发位置在于：

- 五阶段情景推演流程
- 事件驱动研究方法
- 多角色社会模拟
- 情景报告与传播路径
- 图谱化关系展示思路

它回答的是：事件情景怎么演，叙事路径怎么推演。

## A股智研台融合后的目标

三者收敛之后，A股智研台的长期目标包括：

- A股本土化数据
- 中文报告
- 本地模拟盘
- 多 Agent 分析
- 情景推演
- 风控审查
- 决策记忆
- OpenClaw 调度
- 轻量 GUI

也就是说，A股智研台未来并不是“三个项目的拼装”，而是：

- 用 A 股场景重构自己的长期架构
- 用本地数据和中文报告形成自己的产品表达
- 在自有版权体系下逐步自研实现

## 哪些思想可借鉴，哪些实现未来可自研

### TradingAgents 的多角色研究结构可借鉴

可以借鉴：

- 角色分工
- 多空论证
- 风控审查
- 结构化输出

未来可自研实现：

- A 股版技术面 / 公告 / 新闻 / 行业角色
- 研究建议和风险提示格式
- 决策记忆与复盘机制

### FinceptTerminal 的产品模块组织可借鉴

可以借鉴：

- 工作台式产品模块
- DataHub 概念
- 报告中心 / 风控中心 / 自选中心布局思想

未来可自研实现：

- 本地 A股终端工作台
- GUI Terminal
- 本地 DataHub 和数据源注册表

### MiroFish 的五阶段情景推演可借鉴

可以借鉴：

- Graph Building
- Environment Setup
- Simulation
- Report Generation
- Deep Interaction

未来可自研实现：

- A 股版 Scenario Lab
- 事件冲击与叙事传播分析
- 三情景输出与人工复核建议

## 未来 UI 与金融终端化技术路线

A股智研台最终 UI 目标，是本地 A股智能投研终端，而不是普通脚本工具。

在展示层和交互层上，可以综合借鉴：

- TradingAgents 的多 Agent 流程展示思路
- FinceptTerminal 的金融终端产品形态
- MiroFish 的关系图谱和情景推演表现方式

但必须明确：

- 只借鉴产品思想和交互形态
- 不复制第三方源码
- 不复刻 FinceptTerminal 的 UI
- 不复刻其 trade dress
- 不复刻其 terminal command
- 不复刻其快捷键体系

推荐长期技术路线：

- Python Core
- PySide6 桌面壳
- Markdown / HTML 报告
- ECharts 金融图表
- Cytoscape.js 或类似图谱组件用于 Scenario Lab
- SQLite / DuckDB 作为本地数据底座
- OpenClaw 作为未来调度层

推荐 UI 阶段路线：

- V0.2-V0.3：继续 CLI + Markdown
- V0.4：增强 HTML 报告
- V0.5：轻量 GUI 原型
- V0.6：Agent 工作台
- V0.7：Scenario Lab 图谱推演
- V1.0：本地智能投研终端

当前阶段只写入架构文档，不实现 GUI 代码，不引入新依赖。

## 许可证与复用边界

必须明确以下原则：

- 不复制 AGPL 项目源码
- Apache-2.0 代码即使未来复用，也必须保留许可证和 NOTICE
- TradingAgents 当前也只做研究，不直接复制源码
- FinceptTerminal 只学习架构与产品形态
- MiroFish 只学习情景推演思想

未来如需复用第三方代码，必须：

1. 单独评估许可证
2. 保留 `LICENSE` / `NOTICE`
3. 明确标注来源
4. 优先自行实现，而不是直接复制

## 当前结论

三项目的研究已经足够形成 A股智研台自己的长期路线：

- TradingAgents 负责启发研究大脑
- FinceptTerminal 负责启发终端外壳
- MiroFish 负责启发情景推演沙盒

V0.1.7 的任务，就是把这三者从“研究素材”正式收敛为“自有架构蓝图”。
