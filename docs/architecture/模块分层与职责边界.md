# 模块分层与职责边界

## 文档定位

本文档用于明确 A股智研台未来长期模块的职责、输入、输出、当前状态与未来状态，并梳理各模块之间的数据流。

## 模块说明

### DataHub

- 职责：统一数据接入、标准化、缓存、注册表与路由
- 输入：AKShare、公告、新闻、指数、行业、未来其他数据源
- 输出：结构化数据接口，供策略、报告、Agent、Scenario Lab 使用
- 当前状态：仅有数据底座雏形，尚未独立成层
- 未来状态：形成统一数据底座

### Data Source Health

- 职责：检查数据源、网络、代理、依赖与采集健康状态
- 输入：环境变量、依赖安装状态、目标站点连通性、示例采集请求
- 输出：健康检查结果、诊断报告、运行前风险提醒
- 当前状态：已实现 `doctor` / `check-data-source`
- 未来状态：与 DataHub、报告中心、终端工作台联动

### Watchlist

- 职责：维护用户关注标的清单
- 输入：用户配置、自选股列表、未来终端操作
- 输出：待跟踪股票集合、观察对象列表
- 当前状态：配置层已有基础 watchlist
- 未来状态：升级为可维护的自选股中心

### Strategy Signals

- 职责：生成基础技术信号与结构化观察结果
- 输入：价格数据、成交量、指标计算结果
- 输出：`daily_signals.csv`、信号摘要、结构化字段
- 当前状态：已由 `run-daily` 提供基础能力
- 未来状态：扩展到指数、行业、事件标签等更多字段

### Report Center

- 职责：汇总并输出日报、周报、复盘报告
- 输入：Strategy Signals、Data Source Health、未来 Agent 与 Scenario Lab 输出
- 输出：Markdown / HTML 报告、报告归档、可读摘要
- 当前状态：已具备 Markdown 日报
- 未来状态：形成完整报告中心

### Paper Trading

- 职责：记录本地模拟盘、持仓、收益、回撤与复盘
- 输入：人工操作、研究建议、未来风险审查结果
- 输出：模拟盘账本、收益记录、复盘输入
- 当前状态：仅规划，未写代码
- 未来状态：成为本地验证层

### Risk Center

- 职责：统一管理风险审查、组合风险、异常暴露与否决机制
- 输入：策略信号、模拟盘、Agent 研究、Scenario Lab 输出
- 输出：风险评级、风险提示、否决意见、人工复核建议
- 当前状态：仅规划，未写代码
- 未来状态：作为核心横切模块存在

### Agent Research

- 职责：负责多角色投研、研究解释、多空辩论和建议汇总
- 输入：DataHub 数据、日报、公告、新闻、行业信息
- 输出：结构化研究结论、风险提示、建议优先级
- 当前状态：仅完成研究文档和路线图
- 未来状态：形成多 Agent 投研层

### Scenario Lab

- 职责：负责事件冲击、叙事传播、政策影响与情景推演
- 输入：公告、新闻、政策、外围冲击、舆情等事件种子
- 输出：乐观/中性/悲观情景、传播路径、风险触发条件、人工复核点
- 当前状态：仅完成研究设计
- 未来状态：形成长期实验模块

### Decision Memory

- 职责：存储研究建议、模拟盘结果、复盘结论和经验迁移
- 输入：Agent 结论、报告、模拟盘记录、风险审查结果
- 输出：复盘记忆、经验摘要、后续研究参考
- 当前状态：仅规划，未写代码
- 未来状态：成为长期知识闭环

### OpenClaw Scheduler

- 职责：负责调度、汇总、监控、提醒和交互
- 输入：日报、报告、健康状态、模拟盘结果、未来 Agent/Scenario Lab 输出
- 输出：任务触发、汇总摘要、提醒消息、统一交互入口
- 当前状态：仅规划，不写代码
- 未来状态：作为调度层而非交易核心

### GUI Terminal

- 职责：提供统一的终端工作台与可视化交互
- 输入：DataHub、报告中心、模拟盘、风险中心、Agent Research、Scenario Lab
- 输出：终端页面、图表、交互式工作区、报告阅读体验
- 当前状态：仅规划，未写代码
- 未来状态：成为本地 A股智能投研终端

## 模块之间的数据流

### 数据源 → DataHub → 策略信号 → 日报

- 各类数据源进入 DataHub
- DataHub 输出标准化数据给 Strategy Signals
- Strategy Signals 生成结构化信号
- Report Center 将其整理为日报

### 数据源 → 模拟盘 → 风控 → 复盘

- 市场数据与人工输入进入 Paper Trading
- Risk Center 审查仓位、回撤与异常暴露
- Decision Memory 沉淀复盘结论

### 事件输入 → Scenario Lab → Agent Research → 风控审查

- 公告、政策、舆情等事件输入进入 Scenario Lab
- Scenario Lab 推演可能路径与情景
- Agent Research 汇总研究观点与解释
- Risk Center 给出最终风险审查与人工复核建议

### 日报/报告 → OpenClaw → 用户交互

- Report Center 输出日报与报告
- OpenClaw 负责调度、摘要和提醒
- 用户通过 CLI 或未来 GUI 接收结果并继续交互

## 当前哪些模块只是规划

当前明确只是规划、不写代码的模块包括：

- DataHub
- Paper Trading
- Risk Center
- Agent Research
- Scenario Lab
- Decision Memory
- OpenClaw Scheduler
- GUI Terminal

当前已经有初步实现基础的模块包括：

- Data Source Health
- Watchlist（基础配置层）
- Strategy Signals
- Report Center（基础日报层）

## 当前结论

V0.1.7 之后，A股智研台的模块边界已经基本清晰：

- 当前先做数据和报告
- 中期再进入模拟盘和 Agent
- 更后期再进入 Scenario Lab、Decision Memory、OpenClaw 和 GUI Terminal

这有助于后续保持最小闭环迭代，避免跳跃式重构。
