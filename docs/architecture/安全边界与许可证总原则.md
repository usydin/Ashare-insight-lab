# 安全边界与许可证总原则

## 文档定位

本文档用于统一说明 A股智研台的安全边界、第三方开源项目使用边界与版权原则。

## 项目安全边界

A股智研台当前和未来都必须坚持以下安全边界：

- 仅研究和模拟盘
- 不构成投资建议
- 不自动实盘下单
- 不接券商接口
- 所有 AI 输出必须经过人工复核

进一步明确：

- 不做真实交易执行
- 不自动点击券商客户端
- 不绕过平台风控、验证码或登录限制
- 不把任意 AI 输出直接转成实盘动作

## 第三方开源项目边界

### TradingAgents

- 许可证：Apache-2.0
- 当前状态：只研究，不复制源码
- 借鉴范围：多角色研究结构、结构化输出、风控辩论、决策记忆思路

### FinceptTerminal

- 许可证：AGPL-3.0 / 商业许可边界更严格
- 当前状态：只学架构与产品形态
- 借鉴范围：终端化产品形态、DataHub、工作台式模块组织
- 明确不做：不复制源码，不复刻 UI、trade dress、terminal command、快捷键体系

### MiroFish

- 许可证：AGPL-3.0
- 当前状态：只学情景推演思想
- 借鉴范围：五阶段情景推演流程、多角色社会模拟、传播路径与情景输出
- 明确不做：不复制源码，不照搬其前后端结构，不把演示收益视为可靠策略

## 本项目版权

本项目版权体系保持如下：

- 开发者：`pL`
- 版权：`Copyright © 2026 @B‘lock10STUdio. All rights reserved.`

这适用于本项目的自有代码、文档、架构设计和产品规划。

## 未来如果复用第三方代码

未来如果确实需要复用第三方代码，必须满足以下原则：

1. 必须单独评估许可证
2. 必须保留原始 `LICENSE` / `NOTICE`
3. 必须标注来源
4. 优先自行实现，不直接复制

也就是说，当前研究文档不能自动转化为未来的代码复用许可。

## 对 UI 与产品形态的额外边界

即使未来进入 GUI 阶段，也仍然需要坚持：

- 只借鉴产品思想和交互形态
- 不复制第三方源码
- 不复刻 FinceptTerminal 的 UI
- 不复刻其 trade dress
- 不复刻其 terminal command
- 不复刻其快捷键体系

## 当前结论

V0.1.7 之后，A股智研台的长期架构方向已经清晰，但边界也同样清晰：

- 可以研究
- 可以规划
- 可以自研
- 不能直接复制
- 不能越过实盘与安全红线
