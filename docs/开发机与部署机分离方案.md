# 开发机与部署机分离方案

## 目标

将“开发、调试、提交”与“长期运行、正式数据保存”分开，降低风险并提升可维护性。

## 开发机职责

- 使用 Trae 编写和修改代码
- 维护 README 与文档
- 本地调试功能
- 提交 GitHub 仓库
- 做小规模测试数据验证

## 部署机职责

- 运行日常任务
- 保存正式数据
- 保存 token 和运行时配置
- 保存模拟盘记录
- 保存日报和复盘报告

## 分离收益

- 避免开发环境影响正式运行
- 减少敏感数据暴露面
- 便于问题定位和环境管理

## 当前阶段说明

本项目当前仍在开发机阶段，部署机相关内容只做结构预留，不做正式上线。
