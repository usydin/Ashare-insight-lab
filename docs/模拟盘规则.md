# 模拟盘规则

## 目的

模拟盘用于验证策略信号与组合表现，不用于生成真实交易指令。

## 基础原则

- 仅记录本地模拟结果
- 仅作为研究参考
- 不与真实券商账户联动

## 初始规则

- 初始资金以 `config/settings.json` 为准
- 手续费率以配置文件为准
- 滑点率以配置文件为准
- 单只股票仓位上限以配置文件为准
- 单日最大亏损约束以配置文件为准

## 第一阶段建议

- 默认按日级别进行信号和持仓演算
- 默认不处理复杂盘口级别撮合
- 默认不实现高频逻辑
- 默认不引入真实委托回报

## 输出结果

后续模拟盘应至少输出：

- 当前现金
- 当前持仓
- 持仓市值
- 总资产
- 当日盈亏
- 累计收益
