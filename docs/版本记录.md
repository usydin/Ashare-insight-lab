# 版本记录

## V0.3.1

- **主题**：Historical Query & Signal Change Summary / 历史数据查询与信号变化摘要。
- **核心成果**：
  - 实现 `app_core/analytics/history_summary.py`，支持从 SQLite 对比最近两次运行快照。
  - 新增 `python3 app.py changes` 命令，直观展示信号变化、资产增减与风险/异常项。
  - `run-daily` 流程自动生成 `data/processed/signal_changes.csv`。
  - 能够识别 `signal_changed`, `level_changed`, `data_status_changed`, `new_asset`, `missing_asset`, `risk_status` 等六类变化。
  - 增强 `history` 命令的友好度，确保空库时不崩溃。
  - 项目版本更新为 `0.3.1`，阶段进入 `Historical Query & Signal Change Summary`。
- **更新文档**：新增 `docs/data/历史信号变化摘要说明.md`，同步更新 README.md, 当前阶段进展.md, 开发计划.md 等。

## V0.3.0

- **主题**：Local Data Asset Foundation / 本地数据资产基础层。
- **核心成果**：
  - 实现 SQLite 本地历史库，作为后续 Dashboard、历史趋势、AI 投研室的数据底座。
  - 新增 `app_core/storage/sqlite_store.py`，使用标准库 `sqlite3` 实现轻量化持久层。
  - 建立结构化表体系：`daily_runs`, `index_signals_history`, `sector_signals_history`, `stock_signals_history`。
  - 集成数据库写入到 `run-daily` 流程，支持全量快照原子写入。
  - 新增 `python3 app.py history` 命令行，支持查看最近运行状态。
  - 保持现有 CSV / Markdown 输出，确保数据库写入失败不影响主流程。
  - 项目版本更新为 `0.3.0`，阶段进入 `Local Data Asset Foundation`。
- **更新文档**：新增 `docs/data/本地数据资产设计说明.md`，同步更新 README.md, 当前阶段进展.md, 开发计划.md 等。
