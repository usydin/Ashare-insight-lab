# 版本记录

## V1.0-alpha-stage-freeze / 2026-05-05

- **主题**：阶段冻结与能力沉淀，完成 V0.9.x 实时行情源、Token 管理、Longbridge 只读接入准备和数据源状态控制台的阶段说明。

### V0.9.3 Longbridge readonly adapter and local token manager

- **新增能力**：
  - 建立 Longbridge readonly adapter 基础层。
  - 建立本地 Token 管理能力：`token-status`、`token-set`、`token-clear`。
  - 支持 `.env` 自动加载与 `.secrets` metadata 管理。
- **安全边界**：
  - 只读行情，不接交易。
  - token 仅本地化保存，不写入 Git。
- **验证结果**：
  - 本地 Token 状态 CLI 可稳定运行。
  - 相关回归测试已通过。
- **当前限制**：
  - 仅完成状态管理与准备层，不涉及交易上下文。

### V0.9.4 Longbridge OAuth readonly token preparation

- **新增能力**：
  - 增强 Longbridge OAuth 本地 token 准备层。
  - 增强环境变量自动加载与只读状态输出。
- **安全边界**：
  - 不输出真实 token。
  - 不写入前端、snapshot、报告或日志。
- **验证结果**：
  - 状态命令无需手动 `source .env` 即可运行。
- **当前限制**：
  - 仍未完成真实 OAuth 授权闭环。

### V0.9.6 OAuthBuilder quote research commands

- **新增能力**：
  - 新增 `longbridge-sdk-status`、`longbridge-oauth-help`、`longbridge-oauth-start`、`longbridge-oauth-quote`。
  - 完成 `OAuthBuilder -> Config.from_oauth -> QuoteContext` 最小只读研究链路验证框架。
- **安全边界**：
  - 严禁 `TradeContext`。
  - 不读资产、持仓、订单，不下单。
- **验证结果**：
  - SDK 4.0.5 可导入。
  - `Config`、`QuoteContext`、`OAuthBuilder` 可识别。
- **当前限制**：
  - Longbridge 仅为候选源，未成为默认源。

### V0.9.6.1 OAuth internal_server_error diagnostics

- **新增能力**：
  - 增强 OAuthBuilder 授权失败后的脱敏诊断输出。
  - 输出 `error_type`、`likely_stage`、`sdk_version`、`redirect_uri_scheme`、`redirect_uri_host` 等字段。
- **安全边界**：
  - 不输出完整授权 URL、state、token、App Secret。
- **验证结果**：
  - 已在真实失败场景中定位到 `Authorization Failed / internal_server_error`。
- **当前限制**：
  - 当前问题更接近 Longbridge OAuth 服务端、client 配置、`redirect_uri` 或账号权限侧问题。

### V0.9.7 realtime source status and switch prototype

- **新增能力**：
  - 新增 `source-status` 多数据源状态摘要。
  - `ui_snapshot` 已纳入 `source_status`。
  - RealtimeMarketView 已增加行情源状态与切换视觉原型。
  - SettingsView 已区分 API Token 状态与数据源状态。
- **安全边界**：
  - 只做状态展示与视觉原型，不改变真实后端取数源。
  - 不输出真实 token 或完整 OAuth URL。
- **验证结果**：
  - `pytest 186 passed`。
  - `frontend-react` 构建成功。
  - `source-status`、`token-status`、`longbridge-status` 可稳定运行。
- **当前限制**：
  - Longbridge OAuth 仍被 `internal_server_error` 阻塞。
  - Longbridge 暂不作为默认行情源。

## V0.7.1

- **主题**：Local Cache Fallback / 本地缓存兜底基础能力。
- **核心成果**：

  - `run-daily` 轻量接入 `DataSourceManager`，在缓存兜底成功时继续计算指标并保留原始在线失败说明。
