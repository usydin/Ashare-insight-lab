# 版本记录

## V0.2.2

- **主题**：A股指数数据接入与日报观察增强。
- **核心成果**：
  - 新增 `config/market_indices.json` 配置文件，涵盖 A 股主要宽基指数。
  - 新增 `app_core/market_indices.py`，实现指数配置的标准化加载与过滤。
  - 新增 `app_core/data_sources/index_provider.py`，封装基于 AKShare 的指数历史数据采集。
  - 集成指数分析到 `run-daily` 流程，在处理自选股前先采集并分析大盘指数趋势。
  - 升级 Markdown 日报，新增“市场指数观察”章节，输出 `index_signals.csv`。
  - 项目版本更新为 `0.2.2`，阶段调整为 `Data Enhancement - Indices`。
- **更新文档**：README.md, 当前阶段进展.md, 开发计划.md, 版本记录.md, V0.2功能路线说明.md。

  - 新增 `app_core/watchlist.py`，统一处理 watchlist 标准化、默认值与启用项过滤。
  - 增强 `daily_signals.csv` 输出字段，使成功和失败记录都保留 watchlist 元信息。

  - 将项目版本小范围更新为 `0.2.1`，保持 `dev` 阶段。
- **更新文档**：README.md, 当前阶段进展.md, 开发计划.md, 版本记录.md, V0.2功能路线说明.md。
