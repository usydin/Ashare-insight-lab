# V1.0-alpha 行情源控制台阶段冻结说明

## 阶段范围

本阶段覆盖以下能力从“可运行”走向“可说明、可展示、可冻结”的全过程：

- AkShare 实时行情 / K 线
- Marketaux 国际新闻
- 本地 Token 管理
- Longbridge 只读行情接入准备
- Longbridge OAuthBuilder 研究与诊断
- 多数据源状态控制台
- React 前端状态展示
- UI snapshot schema 接入

## 阶段成果

### 数据源接入

- `AkShare` 已作为默认 A 股实时行情源。
- `Marketaux` 已作为国际新闻源。
- `Longbridge` 已作为候选只读行情源完成准备层与状态识别。
- `Tushare` 处于预留状态。

### Token 管理

- 已支持 `.env` 自动加载。
- 已支持 `token-status`、`token-set`、`token-clear`。
- 已支持 `.secrets` metadata 管理与脱敏显示。

### Longbridge OAuth 研究

- 已确认 SDK `4.0.5` 可导入。
- 已确认 `Config`、`QuoteContext`、`OAuthBuilder` 可用。
- 已确认 `OAuthBuilder` 可生成授权 URL。
- 已确认浏览器授权页当前返回 `Authorization Failed / internal_server_error`。

### 前端状态展示

- RealtimeMarketView 已增加行情源状态区。
- 已增加数据源切换视觉原型。
- SettingsView 已区分 API Token 状态与数据源状态。

### Snapshot Schema

- `source_status` 已进入 `ui_snapshot`。
- 前端 snapshot 仅包含脱敏状态，不包含真实 token 或完整 OAuth URL。

## 核心命令

```bash
python3 app.py source-status
python3 app.py token-status
python3 app.py longbridge-status
python3 app.py longbridge-sdk-status
python3 app.py longbridge-oauth-help
python3 app.py quote --symbol 600519 --market CN
python3 app.py kline --symbol 600519 --market CN --period daily --adjust qfq --limit 20
python3 app.py international-news --ticker AAPL --market US --hours 72 --limit 3
```

## 安全边界

- 只读行情
- 不接交易
- 不导入 `TradeContext`
- 不读资产 / 持仓 / 订单
- 不下单 / 撤单 / 改单
- token 本地化保存
- 不提交 `.env`、`.secrets`、`data`、`logs`、`reports`、`dist`、`target`

## 验收结果

- `pytest 186 passed`
- `frontend-react` build 成功
- `validate-snapshot` 通过
- 密钥扫描无输出

## 当前限制

- Longbridge OAuth 当前仍返回 `internal_server_error`
- 当前没有真实 OAuth token
- Longbridge 当前不能作为默认行情源
- 当前未接 WebSocket 自动刷新
- 当前未接 Tushare 真实数据
- 当前未接 AI 研报生成
