# 项目说明

## 项目名称

- 中文名：A股智研台
- 英文名：AShare Insight Lab

## 项目定位

本项目是一个面向 Mac 本地环境的 A 股智能投研与模拟盘平台，当前重点是建立研究流程、数据流程、策略验证流程和报告输出流程。

本项目的底层核心由 Python 平台实现，负责数据采集、数据存储、策略信号、模拟盘、风控和报告等关键能力。

OpenClaw 不定位为底层交易核心，而是后续接入的本地 AI Agent 与自动化调度层，用于在 Python 平台之上承接任务触发、信息汇总、结果解读和交互入口能力。

## 当前阶段

- 阶段版本：`V0.1 dev skeleton`
- 当前任务：完成项目骨架修复与初始化
- 当前状态：目录已建立，配置文件已存在，后续进入功能模块逐步实现阶段

## 第一阶段范围

包括：

1. 本地数据采集
2. 策略信号
3. 本地模拟盘
4. 日报生成
5. 复盘报告

不包括：

1. 实盘自动交易
2. 自动下单
3. 模拟客户端点击操作
4. 绕过平台限制
5. 交易接口复刻

## 设计原则

- 先搭骨架，再填功能
- 先保证安全边界，再扩展能力
- 优先本地可运行、可验证、可维护
- 开发机与部署机职责分离
- Python 平台负责底层核心能力，OpenClaw 负责后续 AI 调度与交互扩展
