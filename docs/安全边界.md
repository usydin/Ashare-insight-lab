# 安全边界

## 核心原则

本项目第一阶段仅用于本地研究、策略验证和模拟盘管理，不触碰真实交易执行。

## 允许范围

- 本地数据采集
- 指标计算与策略信号生成
- 本地模拟盘记录
- 本地日报与复盘报告生成
- 开发文档、配置管理和代码维护

## 禁止范围

- 实盘自动交易
- 自动下单
- 模拟鼠标键盘点击交易客户端
- 绕过验证码、登录风控或平台限制
- 抓包复刻交易接口

## 敏感信息规则

- `.env` 不入库
- token、API key 不入库
- 正式数据库不入库
- 日志文件不入库
- 真实原始数据和正式输出报告不入库

## 执行要求

- 所有新增功能都必须先判断是否越过安全边界
- 如功能可能触及交易执行、账户控制或平台限制绕过，应直接停止实现并重新评估
