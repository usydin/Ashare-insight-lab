# V1.0-alpha 演示操作说明

## 启动前检查

建议在项目根目录依次执行：

```bash
git status --short
source .venv/bin/activate
python3 app.py doctor
python3 app.py source-status
python3 app.py token-status
```

检查重点：

- 工作区应为 clean
- Python 虚拟环境应已激活
- 数据源健康检查命令可运行
- `source-status` 可显示 AkShare / Longbridge / Marketaux / Tushare
- `token-status` 只显示脱敏状态

## 生成数据快照

```bash
python3 app.py run-daily
python3 app.py ui-snapshot
python3 app.py validate-snapshot
python3 app.py sync-frontend-snapshot
```

说明：

- `run-daily` 用于生成最新研究数据、日报和 SQLite 快照
- `ui-snapshot` 用于生成前端消费的统一 snapshot
- `validate-snapshot` 用于校验结构完整性
- `sync-frontend-snapshot` 用于把后端快照同步到前端静态目录

## 启动前端

```bash
cd frontend-react
npm run build
npm run dev
```

说明：

- `npm run build` 用于演示前的构建校验
- `npm run dev` 默认使用现有前端预览方式
- 如演示环境已有桌面壳或预览方式，可按当前本机展示流程打开

## 演示重点

建议按以下顺序演示：

1. Dashboard 总览
2. RealtimeMarketView 实时行情原型
3. 行情源状态区
4. SettingsView 的 Token 状态与数据源状态
5. Longbridge OAuth 阻塞说明
6. 全局只读安全边界

## 演示讲解要点

- 默认行情源当前为 `AkShare`
- `Marketaux` 用于国际新闻，不作为交易信号
- `Longbridge` 当前为候选只读行情源，受 OAuth 阻塞影响
- 前端切换当前为视觉原型，不改变真实后端取数源
- 项目当前强调研究、状态透明和安全边界

## 不演示内容

- 不演示交易
- 不演示真实 token
- 不展示 `.env`
- 不展示完整 OAuth URL
- 不展示 App Secret
- 不演示资产 / 持仓 / 订单
