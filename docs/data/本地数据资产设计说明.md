# 本地数据资产设计说明 (V0.3.0)

## 概述

从 V0.3.0 版本开始，A股智研台（AShare Insight Lab）引入了基于 SQLite 的本地数据资产基础层。该层旨在将原本零散的 CSV 和 Markdown 输出进行结构化持久化，为后续的历史趋势分析、Dashboard 展示以及 AI 投研室提供稳定的数据底座。

## 设计目标

1. **结构化存储**：将每次 `run-daily` 的运行元信息及产生的指数、板块、个股信号完整记录。
2. **历史追溯**：支持查询任一资产（指数/板块/个股）的历史信号变化趋势。
3. **零重依赖**：优先使用 Python 标准库 `sqlite3`，不引入 SQLAlchemy 等重型 ORM 框架，保持轻量。
4. **非破坏性**：不影响现有的 CSV 和 Markdown 报表生成逻辑。
5. **高可用性**：数据库写入失败不应阻塞主流程，仅记录警告信息。

## 数据库架构

### 存储路径
- 默认路径：`data/history/ashare_insight_lab.sqlite3`
- 该目录及数据库文件已被列入 `.gitignore`，不提交至 Git 仓库。

### 核心表结构

#### 1. daily_runs (运行历史表)
记录每次 `run-daily` 的全局元信息。
- `id`: 自增主键
- `run_date`: 运行日期 (YYYY-MM-DD)
- `started_at`: 开始时间
- `finished_at`: 结束时间
- `app_version`: 应用版本
- `status`: 运行状态 (success/failed)
- `index_count`: 处理的指数数量
- `sector_count`: 处理的板块数量
- `stock_count`: 处理的个股数量
- `report_path`: 对应日报的相对路径
- `processed_csv_path`: 对应汇总 CSV 的相对路径

#### 2. index_signals_history (指数信号历史表)
- `run_id`: 关联 `daily_runs.id`
- `symbol`: 指数代码
- `name`: 指数名称
- `close/ma5/ma20`: 价格与均线数据
- `signal`: 信号类型 (trend_up/trend_down/neutral)
- `signal_level`: 信号强度

#### 3. sector_signals_history (行业/板块信号历史表)
- `run_id`: 关联 `daily_runs.id`
- `symbol`: 板块代码
- `board_type`: 板块类型 (行业/概念)
- `close/ma5/ma20/signal/signal_level`: 信号数据

#### 4. stock_signals_history (个股信号历史表)
- `run_id`: 关联 `daily_runs.id`
- `code`: 股票代码
- `name`: 股票名称
- `industry/sector/board`: 归属信息
- `tags`: 标签（逗号分隔）
- `close/ma5/ma20/signal/signal_level`: 信号数据

## 使用方式

### 自动写入
在执行 `python3 app.py run-daily` 时，系统会自动将结果写入数据库。

### 命令行查询
使用以下命令查看最近的运行记录：
```bash
python3 app.py history
```
