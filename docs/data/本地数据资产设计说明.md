# 本地数据资产设计说明 (V0.3.0)

## 概述

从 V0.3.0 版本开始，A股智研台（AShare Insight Lab）引入了基于 SQLite 的本地数据资产基础层。该层旨在将原本零散的 CSV 和 Markdown 输出进行结构化持久化，为后续的历史趋势分析、Dashboard 展示以及 AI 投研室提供稳定的数据底座。

## 设计目标

1. **结构化存储**：将每次 `run-daily` 的运行元信息及产生的指数、板块、个股信号完整记录。
2. **历史追溯**：支持查询任一资产（指数/板块/个股）的历史信号变化趋势。
3. **零重依赖**：优先使用 Python 标准库 `sqlite3`，不引入 SQLAlchemy 等重型 ORM 框架，保持轻量。
4. **非破坏性**：不影响现有的 CSV 和 Markdown 报表生成逻辑。
5. **高可用性**：数据库写入失败不应阻塞主流程，仅记录警告信息。

## 历史摘要查询 (V0.3.1)

V0.3.1 引入了 `app_core/analytics/history_summary.py`，提供了对比两次运行快照的能力：

- `get_latest_run_pair()`: 获取最近两次成功运行。
- `build_signal_change_summary()`: 对比信号差异，识别 `signal_changed`, `new_asset`, `risk_status` 等。
- `python3 app.py changes`: CLI 展示入口。

## 使用方式

### 自动写入
在执行 `python3 app.py run-daily` 时，系统会自动将结果写入数据库。

### 命令行查询
使用以下命令查看最近的运行记录：
```bash
python3 app.py history
```
