# 长桥 OpenAPI 只读行情接入说明（V0.9.3）

- 定位：仅作为只读行情源候选，不接交易、资产、持仓、订单，不接推送。
- 环境变量（必需）：`LONGBRIDGE_APP_KEY`、`LONGBRIDGE_APP_SECRET`、`LONGBRIDGE_ACCESS_TOKEN`
- 环境变量（可选）：`LONGBRIDGE_REGION`、`LONGBRIDGE_HTTP_URL`、`LONGBRIDGE_QUOTE_WS_URL`
- 安全规则：不保存 token，不打印 token，不写入快照/报告，不提交到 Git。
- A 股代码映射：内部 `600519/000001/300750` → 长桥 `600519.SH/000001.SZ/300750.SZ`
- CLI 示例：
  - `python3 app.py longbridge-status`
  - `python3 app.py longbridge-quote --symbol 600519 --market CN`
- 常见状态：`missing_env`、`sdk_missing`、`unsupported_market`、`unsupported_symbol`、`fetch_failed`
- 后续路线：评估 WebSocket 推送、批量刷新、前端数据源切换；仍不接交易接口
