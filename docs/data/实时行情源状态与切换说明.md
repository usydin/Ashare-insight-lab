# 实时行情源状态与切换说明

## 当前阶段说明

- 当前文档对应 `V0.9.7 realtime source status and switch prototype` 的冻结结果。
- `source_status` 已进入 frontend snapshot。
- 前端切换当前仅为视觉原型，不改变真实后端数据源。
- Longbridge 当前暂不设为默认源。

## 当前默认源

- 当前默认实时行情源为 `AkShare`。
- 当前已用于 A 股实时行情与 K 线能力，适合作为 V0.9.7 阶段的稳定默认源。
- 前端和 CLI 中展示的数据源切换，当前仍以 `AkShare` 为真实生效源。

## Longbridge 候选源状态

- `Longbridge OpenAPI` 当前定位为候选只读行情源，不作为默认源。
- 当前已完成 SDK 可导入、`OAuthBuilder` 授权 URL 生成、状态诊断与只读安全边界封装。
- 当前阻塞点不是交易链路，而是 OAuth 授权阶段返回 `Authorization Failed / internal_server_error`。
- 在该阻塞解除前，前端只展示状态，不执行真实切换。

## Marketaux 新闻源状态

- `Marketaux` 已作为国际市场新闻源接入。
- 该源用于国际新闻观察与辅助研判，不作为交易信号。
- CLI 与状态摘要中只展示 `configured / missing / empty` 等脱敏状态，不输出真实 token。

## Tushare 预留状态

- `Tushare Pro` 当前为预留数据源。
- 后续计划用于 A 股历史、财务与基础数据补充。
- 本轮只展示状态位，不接入真实前端切换逻辑。

## 为什么暂不把 Longbridge 设为默认

- Longbridge 当前未完成稳定 OAuth 授权闭环，真实 token 尚未生成。
- 当前授权失败结论更接近 Longbridge OAuth 服务端、OAuth client 配置、`redirect_uri` 或账号权限侧问题。
- 为避免默认源不稳定，本轮继续以 `AkShare` 作为实时行情默认源。

## OAuth 阻塞说明

- 当前实际现象为授权页返回 `internal_server_error`。
- 已确认本地代码可完成 SDK 导入、OAuthBuilder 启动与脱敏诊断输出。
- 当前建议继续排查：
  - Longbridge 开发者后台是否已启用 OAuth 2.0
  - App Key 是否可作为 OAuth `client_id`
  - `redirect_uri` 是否需要登记且与当前值一致
  - 当前账号、区域或行情权限是否支持该授权链路

## 安全边界

- 只读行情
- 不接交易
- 不读资产 / 持仓
- 不下单 / 撤单
- 不把 token 写入 Git / logs / reports / snapshot / frontend json
- 不在前端展示完整 token、完整 OAuth URL 或 App Secret

## 后续路线

- 解决 Longbridge OAuth 阻塞后，再启用真实行情源切换
- 增加 source preference 配置
- 增加前端实时行情源切换
- 增加数据源健康评分与可用性展示
