# A股智研台 Agent 路线图

## 路线图定位

本文档用于说明 A股智研台未来可能演进出的 Agent 层路线。当前仅做规划，不代表已经实现。

## V0.2 数据源与日报增强

目标：

- 增强数据源稳定性
- 扩充日报字段和解释能力
- 增加公告、新闻、行业等结构化输入

重点：

- 继续强化 `run-daily`
- 继续强化 `doctor`
- 提高日报的研究可读性
- 为未来报告中心与终端工作台预留稳定输出格式

## V0.3 模拟盘账本

目标：

- 建立本地模拟盘账本
- 记录持仓、现金、交易、收益和回撤
- 为后续复盘与建议验证打基础

边界：

- 仅限本地模拟盘
- 不连接真实券商
- 不自动下单

## V0.4 Agent 研究报告层

目标：

- 在底层数据与日报之上，增加多角色研究输出
- 从“信号结果”升级到“研究解释”
- 让 Agent 输出可以进入报告中心与未来终端工作台

可能能力：

- 技术面分析员
- 公告/财报分析员
- 新闻宏观分析员
- 行业板块分析员

## V0.5 多空辩论与风控审查

目标：

- 引入看多与看空的双向论证
- 引入风险审查角色
- 让研究结论经过更充分的反方检验
- 为未来 `Agent Arena / 多策略对比` 提供基础结构

预期收益：

- 减少单边结论
- 提升研究建议质量
- 强化风控意识

## V0.6 决策记忆与复盘

目标：

- 建立研究决策记忆
- 让系统回看哪些建议有效，哪些建议失效
- 将复盘结果输入后续研究流程
- 让决策记忆与报告中心、模拟盘复盘逐步联动

这一步可借鉴：

- 决策日志
- 复盘反思
- 同类标的经验迁移

## V0.7 OpenClaw 调度与 24 小时部署

目标：

- 由 OpenClaw 负责调度、汇总、交互和异常监控
- 由独立部署机长期运行
- 将 doctor、run-daily、日报、复盘等流程连接起来

边界：

- OpenClaw 只做调度与交互层
- 不作为交易执行核心

## 与终端化路线的结合

未来 Agent 层应逐步与以下模块结合，但当前不实现代码：

- **终端化工作台 (GUI)**：展示 Agent 的研究过程、对垒过程及最终研报。
- **DataHub / 数据源注册表**：为 Agent 提供统一、标准化、带缓存的数据入口。
- **报告中心**：归档 Agent 生成的深度研究报告，支持按标的、按日期检索。
- **模拟盘账本**：Agent 生成“建议仓位”，模拟盘负责“模拟执行”并反馈收益结果。
- **风控中心**：Agent 发现异常波动或基本面风险时，实时向终端推送警报。
- **决策记忆与复盘系统**：记录 Agent 的每一笔建议及后续表现，形成 AI 的“投资笔记”。

原则上：

- Agent 层负责研究解释与建议生成
- 终端工作台负责展示、筛选、对比与归档
- DataHub 负责提供统一数据入口
- 模拟盘负责验证建议，不负责实盘执行

## 始终不做的内容

无论路线图如何推进，以下内容始终不做：

- 自动实盘交易
- 自动下单
- 模拟点击券商客户端
- 绕过验证码或平台风控
- 抓包复刻交易接口

## 当前结论

当前阶段最适合推进的不是“直接实现多智能体”，而是：

1. 先把底层数据与报告层打稳
2. 再把模拟盘账本打稳
3. 再逐步考虑 Agent 层与终端化工作台的结合
4. 最后才考虑 DataHub、调度层与长期工作台演进

这样更符合 A股智研台当前的工程成熟度与安全边界。
