# Apache-2.0 第三方代码使用边界

## 说明

本文档用于说明 A股智研台在研究第三方开源项目时的边界，避免未来在代码使用、改造和版权声明方面出现混淆。

## TradingAgents 的身份

- TradingAgents 是第三方开源项目
- 它不属于 A股智研台
- 它的作者、版权主体和开源维护体系与本项目不同

## License 情况

- TradingAgents 使用 Apache-2.0 协议

Apache-2.0 允许一定范围内的使用、修改与分发，但前提是遵守其协议要求，特别是保留版权、许可证与 NOTICE 信息。

## 当前阶段边界

当前阶段：

- 只学习其架构设计
- 只做源码结构研究
- 不复制其源码
- 不把其实现直接并入本项目
- 不把其 Agent、Graph、CLI 或数据层代码改名后当作自有代码使用

## 未来如复制或修改源码

如果未来确实要复制、改造或嵌入部分第三方源码，必须至少满足：

1. 保留原始 `LICENSE`
2. 保留原始版权声明
3. 保留原始 `NOTICE` 文件或等效说明
4. 明确标注来源仓库与来源路径
5. 明确说明哪些代码来自第三方、哪些代码属于本项目自有改动

## 建议的来源记录方式

建议未来建立以下其中一种目录用于记录第三方来源：

- `third_party/`
- `docs/third_party/`

记录内容建议包括：

- 第三方项目名称
- 仓库地址
- 协议类型
- 引入时间
- 引入版本
- 源文件路径
- 本地修改说明

## 本项目自有版权说明

即使未来学习或参考第三方架构，本项目自有版权体系仍然保持不变：

- Copyright © 2026 @B‘lock10STUdio. All rights reserved.

这只适用于本项目自有代码、文档和自有设计内容，不自动覆盖任何第三方源码版权。

## 当前结论

当前阶段明确结论：

- TradingAgents 仅作为第三方开源架构研究对象
- 本项目当前不复制其任何源码
- 本项目当前不引入其依赖
- 本项目当前只沉淀“可借鉴的架构思想”和“未来适配规划”
