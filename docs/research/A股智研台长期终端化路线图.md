# A股智研台长期终端化路线图

## 1. 路线图定位
本路线图描述 A股智研台从当前 CLI 阶段向未来本地智能投研终端演进的愿景。
**核心原则**：安全第一、数据本地、AI 辅助、拒绝实盘自动交易。

## 2. 演进阶段
### V0.2 数据源与日报增强
- **核心**：提高 `run-daily` 稳定性。
- **目标**：支持更多 A股维度（公告、新闻、行业），输出更精美、更具研究价值的 Markdown 报告。

### V0.3 本地模拟盘账本
- **核心**：实现一个轻量级本地模拟交易记录系统。
- **目标**：用户可手动记录模拟交易，系统自动计算收益率、回撤及盈亏曲线，为 AI 复盘提供数据。

### V0.4 AI Agent 研究报告层
- **核心**：引入角色化分析员（技术面、基本面、舆情）。
- **目标**：日报从“数据摘要”进化为“多角色投研研报”，提供更深度的决策支持。

### V0.5 多空辩论与 Agent Arena
- **核心**：实现看多/看空 Agent 的对冲分析。
- **目标**：针对同一标的生成对立观点，强化风控审查，避免单向偏见。

### V0.6 决策记忆与复盘系统
- **核心**：建立本地决策知识库。
- **目标**：AI 自动回看历史建议的有效性，记录“经验教训”，实现持续进化。

### V0.7 数据源注册表与 DataHub 雏形
- **核心**：重构数据层，抽象出统一的数据连接器接口。
- **目标**：支持多种数据源（AKShare, 东财, 爬虫等）平滑切换与本地缓存。

### V0.8 轻量 GUI 工作台
- **核心**：引入基于 Python 的 GUI 框架（如 PySide6 或 Flet）。
- **目标**：提供仪表盘、报告阅读器、自选管理等可视化界面。

### V0.9 OpenClaw 调度与 24 小时运行
- **核心**：集成 OpenClaw 调度器。
- **目标**：支持在服务器/部署机上 24 小时自动运行、状态监控与远程交互。

### V1.0 本地 A股智能投研终端稳定版
- **核心**：整合上述所有模块，形成稳定的产品化终端。
- **目标**：提供流畅的本地投研体验，成为 A股投资者的智能工作站。

## 3. 安全与合规边界
- **AI 角色限制**：AI 只生成研究建议和模拟盘操作建议。
- **操作限制**：严禁 AI 自动实盘下单、自动连接券商接口或模拟点击。
- **隐私限制**：所有用户数据、持仓、密钥均保存在本地，不上传云端。

## 4. 总结
本路线图旨在通过分阶段迭代，逐步将 A股智研台打造为一个专业、智能、安全的本土化投研工具。当前所有工作（V0.1.x）均为后续阶段夯实地基。
