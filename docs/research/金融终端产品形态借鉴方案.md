# 金融终端产品形态借鉴方案

## 文档定位
本文档旨在基于 FinceptTerminal 的研究，规划 A股智研台未来的终端化产品形态。
**注意**：本文档仅为规划，当前不实现 GUI、模拟盘或任何终端交互代码。

## 1. A股智研台未来终端化模块规划
借鉴 FinceptTerminal 的 Screens 组织方式，本项目未来的 GUI/工作台应包含以下核心分区：

- **运行概览 (Dashboard)**：显示系统状态、今日已生成报告数、数据更新进度。
- **自选股中心 (Watchlist)**：管理自选列表，快速触发单股深度扫描。
- **市场指数 (Markets)**：A股大盘指数、成交量、涨跌分布实时/历史可视化。
- **行业板块 (Sectors)**：行业热度地图、资金流向、领涨领跌板块分析。
- **数据源健康中心 (Health Center)**：可视化展示 `doctor` 结果，管理 API Key、代理设置。
- **报告中心 (Report Center)**：日报/周报/复盘报告的归档、筛选与阅读器。
- **模拟盘账户 (Paper Trading)**：本地虚拟资产管理、盈亏曲线、持仓流水。
- **风控中心 (Risk Control)**：组合集中度预警、波动率监控、回撤分析。
- **AI Agent 工作台 (Agent Studio)**：配置不同角色的 AI 参数，查看其研究过程。
- **决策记忆 (Memory Bank)**：历史研究结论的回测、复盘、反思记录。
- **Agent Arena / 多策略对比**：不同 Agent 组合对同一标的的观点对比。
- **设置与部署状态 (System)**：配置本地运行目录、OpenClaw 调度参数、日志级别。

## 2. 短期形态：CLI + Markdown + CSV/JSON
- **输入**：命令行参数（如 `python app.py run-daily`）。
- **输出**：
  - 本地 Markdown 报告（可读性）。
  - 本地 CSV/JSON 数据（可分析性）。
  - 控制台实时日志（诊断性）。
- **优势**：轻量、稳定、易于 CI/CD。

## 3. 中期形态：轻量 GUI 工作台
- **技术选型**：考虑 PySide6 (原生感) 或 Flet (Flutter 渲染，开发快)，当前不落地。
- **定位**：作为 CLI 的可视化外壳，支持点击运行、报告阅读、图表预览。
- **核心逻辑**：UI 层调用现有的 `app_core` 模块，保持业务逻辑唯一。

## 4. 长期形态：本地 A股智能投研终端
- **定位**：比肩专业金融终端的本地化投研工作站。
- **特色**：
  - 数据全量本地缓存。
  - AI 深度介入分析。
  - 支持 OpenClaw 远程调度。
  - 极度强调隐私与数据主权。

## 5. 明确边界与不复刻说明
- **不复刻 UI 布局**：不模仿 FinceptTerminal 的分栏方式或窗口管理逻辑。
- **不复刻视觉风格**：本项目将采用独立的 UI 设计语言。
- **不复刻终端命令体系**：不使用 `/` 或专有短代码命令。
- **不复刻 Trade Dress**：不模仿其特定的组件交互方式、配色方案或品牌词汇。
