# 多智能体社会模拟在A股投研中的使用边界

## 文档定位

本文档用于说明多智能体社会模拟能力在 A 股投研中的适用范围与限制，避免将情景推演误用为直接交易工具。

## 适合的使用场景

基于 MiroFish 所体现的架构特点，多智能体社会模拟更适合以下场景：

- 事件冲击推演
- 叙事传播路径分析
- 舆情变化观察
- 政策影响评估
- 市场参与者分歧对比

这类能力更适合回答：

- 某个事件可能如何被不同角色解读
- 哪条叙事路径最容易快速扩散
- 哪类风险在传播过程中可能被放大

## 不适合的使用场景

多智能体社会模拟不适合直接用于：

- 裸预测股价
- 直接生成买入卖出点位
- 直接生成实盘交易动作
- 代替回测、财务分析和基础数据验证

原因在于，这类模拟更偏向“叙事与行为路径推演”，而不是严格可验证的价格预测模型。

## 单次模拟结果不能当作交易信号

必须明确：

- 单次模拟结果不是交易信号
- 单次模拟中的乐观或悲观结论不能直接转化为仓位动作
- 单次推演中的个别角色观点不能替代研究结论

更合理的使用方式是把它视作：

- 一种补充性的研究视角
- 一种事件风险预演工具
- 一种供研究员人工复核的参考层

## 情景推演只作为研究参考

未来即使 A股智研台增加情景推演能力，也应将其定位为：

- 研究参考
- 风险提醒
- 复盘辅助

而不是：

- 自动决策引擎
- 自动交易模块
- 收益承诺工具

## 必须经过模拟盘和人工复核

任何来自情景推演的结论，未来都必须经过至少两层过滤：

1. 模拟盘验证
2. 人工复核

推荐流程是：

- 先做事件推演
- 再做 Agent 研究汇总
- 再进入模拟盘观察
- 最后由人工判断是否采纳

## 成本与复杂度控制

多智能体社会模拟通常消耗较高，必须控制：

- Token 成本
- Agent 数量
- 交互轮次
- 推演范围

否则容易出现：

- 成本不可控
- 输出噪声增加
- 结论稳定性下降
- 难以复盘与复现

对 A股智研台而言，未来若真要落地，应优先选择：

- 更少的角色
- 更短的轮次
- 更聚焦的事件
- 更明确的结构化输出

## 对演示收益的认知边界

必须明确：

- 不能把视频中的 BTC / Polymarket 收益展示当成可靠策略
- 不能把演示案例当成可复制的盈利模型
- 不能把“案例好看”误判为“可用于 A 股实战”

演示视频的价值在于说明：

- 多智能体推演可以生成丰富叙事路径
- 社会模拟可以帮助理解群体行为

而不是证明：

- 其结果天然具备可交易性
- 其输出能稳定转化为收益

## 对 A股智研台的实际边界

当前阶段明确边界如下：

- 不实现社会模拟代码
- 不把情景推演接入 `run-daily`
- 不改变 `doctor` 逻辑
- 不接入真实交易
- 不自动下单
- 不引入 MiroFish 相关依赖

## 当前结论

多智能体社会模拟在 A 股投研中的最佳位置，是“事件冲击研究辅助层”，而不是“交易信号生成器”。

它最适合帮助研究员回答：

- 风险会如何传播
- 哪类叙事最可能放大
- 哪些分歧点需要重点盯住

但最终是否形成投资结论，仍要回到：

- 数据验证
- 模拟盘观察
- 风控审查
- 人工判断
