# 开源金融项目借鉴总览

## 1. 核心研究对象对比
| 特性 | **TradingAgents** | **FinceptTerminal** | **MiroFish** |
| :--- | :--- | :--- | :--- |
| **定位** | AI 多智能体投研大脑 | 金融终端产品外壳与平台组织 | 多智能体情景推演沙盒 |
| **核心优势** | 多角色研究、结构化输出、决策记忆 | 原生终端、DataHub、连接器体系 | 五阶段推演流程、事件传播模拟、角色社会互动 |

## 2. A股智研台应吸收的内容
- **从 TradingAgents 学习**：
  - **分工明确**：将投研拆分为分析员、研究员、风控、PM 等角色。
  - **结构化思维**：不仅输出文字，更要输出可解析的交易评分、风险等级。
  - **决策记忆**：记录“为什么买/卖”，以便后续复盘。
- **从 FinceptTerminal 学习**：
  - **模块化 UI**：按“工作台”逻辑组织功能，如报告中心、数据健康中心。
  - **DataHub 理念**：将数据源接入与业务逻辑分离，通过注册表管理连接器。
  - **本地优先**：强调本地数据缓存与高性能展示。
- **从 MiroFish 学习**：
  - **情景推演流程**：将事件研究拆成图构建、环境配置、模拟、报告、深度交互五阶段。
  - **多角色社会视角**：从散户、机构、媒体、监管等多种角色观察叙事扩散。
  - **研究边界意识**：把推演结果定义为研究参考，而不是交易信号。

## 3. A股智研台不应直接复制的内容
- **不复制源码**：无论是 C++ 还是 Python 源码，严禁直接搬运。
- **不复刻 Trade Dress**：不模仿 FinceptTerminal、MiroFish 的界面布局、配色、快捷键及专有词汇。
- **不引入重依赖**：如 LangGraph、Backtrader、Qt6、Redis、Node.js、Vue、Flask、Zep、OASIS、Docker 等，保持 A股智研台当前的轻量化。
- **不偏离安全边界**：拒绝实盘自动交易，始终坚持“研究建议”定位。

## 4. A股智研台的长期目标
在吸收先进架构思想的基础上，坚持走**本土化、智能化、轻量化**路线：
- **A股本土化数据**：深度适配 AKShare 及国内公告/新闻源。
- **中文投研报告**：生成符合国内投资者阅读习惯的专业报告。
- **本地模拟盘**：在本地验证 AI 建议，而非连接实盘。
- **多 Agent 研究**：形成具有 A股特色的分析员矩阵。
- **情景推演实验室**：增加事件冲击、叙事传播与政策影响的研究层。
- **数据源健康检查**：保持 `doctor` 模块的持续演进。
- **轻量 GUI**：提供流畅的可视化体验，但核心逻辑仍在 Python 内核。
- **OpenClaw 调度**：实现无人值守的自动化分析流。
