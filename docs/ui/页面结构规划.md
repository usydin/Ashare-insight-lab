# 页面结构规划

A股智研台未来 UI 将采用多模块、工作台式的页面结构，旨在为用户提供从“宏观 -> 板块 -> 个股”的深度研究视野。

## 1. 首页 Dashboard
作为用户进入系统的第一屏，提供当日市场的核心摘要：
- **今日市场状态卡片**: 市场涨跌分布、成交量缩放提示。
- **指数概览**: 上证、深证、创业板等核心指数的实时/最新信号。
- **行业/板块观察**: 涨幅靠前或信号发生转变的热门板块。
- **自选股信号摘要**: 核心观察标的的最新 MA 信号变更。
- **数据源健康状态**: AKShare 连接情况与数据新鲜度。
- **最新日报入口**: 一键跳转阅读当日完整的 Markdown 分析报告。
- **风险提示**: 显眼的合规性与投资风险告知。

## 2. 市场指数页
专注于宏观市场趋势：
- **数据可视化**: `index_signals.csv` 的图表化展示。
- **趋势分析**: 多指数叠加对比、MA5/MA20 交叉状态。
- **异常提示**: `stale_data` 或 `fetch_failed` 的可视化反馈。

## 3. 行业/板块页
深入挖掘结构性机会：
- **板块分类**: `concept` (概念) 与 `industry` (行业) 的分层展示。
- **筛选与过滤**: 支持按 `priority` (优先级) 或 `category` 筛选。
- **行业强弱榜**: 观察不同行业板块的趋势一致性。
- **行业轮动预留**: 预留未来展示行业资金流向与轮动周期的区域。

## 4. 自选股工作台
核心投研操作区：
- **Watchlist 管理**: 添加、删除、编辑标的元信息。
- **深度字段展示**: `priority`、`position_status`、`tags` 的标签化展示。
- **信号矩阵**: 清晰的 MA 信号与趋势判断表格。
- **个股详情入口**: 跳转查看个股历史 K 线与详细分析。
- **备注与复盘**: 支持用户在 UI 上直接输入对标的的观察备注。

## 5. 日报中心
报告管理与阅读：
- **日报渲染**: 高质量渲染 `daily_report.md`，支持目录导航。
- **历史归档**: 按日期排列的历史报告列表，支持搜索。
- **导出能力**: 支持将日报导出为 PDF 或分享 HTML 链接（预留）。

## 6. AI 投研室 (未来规划)
基于 AI 代理的研究增强：
- **智能观察笔记**: 自动生成个股/板块的异动原因分析。
- **投研简报**: 每日收盘后的 AI 辅助决策摘要。
- **风险探测器**: 基于基本面与技术面的潜在风险扫描提示。
- *注：仅提供研究参考，不生成直接的交易指令。*

## 7. 情景推演室 (未来规划)
假设驱动的风险演练：
- **假设输入**: "如果上证指数跌破 3000 点"、"如果半导体板块整体回调 5%"。
- **影响评估**: 自动模拟并展示在该情景下，用户自选股的 MA 信号将如何变化。
- **风险沙盒**: 帮助用户在极端行情发生前做好心理与策略准备。

## 8. 设置页
系统配置管理：
- **数据管理**: 数据存储目录、配置文件路径管理。
- **健康自检**: 一键运行 `doctor` 命令并在 UI 展示报告。
- **个性化**: 主题色切换（亮色/暗色）、窗口置顶设置。
- **API 配置**: LLM 服务提供商 API Key 管理（未来预留）。
