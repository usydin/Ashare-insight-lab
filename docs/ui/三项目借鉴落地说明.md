# 三项目借鉴落地说明

A股智研台在规划产品形态时，深度参考了三个开源项目的核心思想，并结合本地 A 股投研场景进行了落地适配。

## 1. FinceptTerminal: 金融终端外壳与工作台

**借鉴点**:
- **金融终端式导航**: 采用侧边栏切换不同研究维度的交互方式。
- **多模块工作台**: 将复杂的金融数据拆解为 Dashboard、市场、资产、图表等独立模块。
- **组织方式**: 借鉴其对海量实时数据与静态报告的有序管理思路。

**在 A股智研台的落地**:
- 统一的 Dashboard 首页，作为“投研仪表盘”。
- 独立的“市场指数页”与“行业/板块页”，将宏观与结构性机会分离。
- 专门的“日报中心”，借鉴其报告预览与管理的逻辑。

## 2. TradingAgents: AI 投研大脑与多角色分析

**借鉴点**:
- **多角色研究 (Agentic Workflow)**: 将投研任务拆分为技术分析员、基本面分析员、风险控制员等角色。
- **结构化输出**: AI 生成的结果必须是高度结构化、可被 UI 直接渲染的。
- **生成思路**: 借鉴其从原始数据到“研究简报”的转化逻辑。

**在 A股智研台的落地**:
- 规划中的“AI 投研室”，未来将集成多角色分析结论。
- 自动化生成的“个股观察笔记”与“行业简报”，丰富研究深度。
- 严格遵循其风险控制思路，仅提供研究建议，不涉及实盘交易。

## 3. MiroFish: 情景推演与复盘实验室

**借鉴点**:
- **情景推演 (Scenario Simulation)**: 通过改变外部参数，观察目标标的的表现变化。
- **假设输入与结果对比**: 提供一种“如果...那么...”的研究工具。
- **复盘沙盒**: 在虚拟环境中演练策略的有效性。

**在 A股智研台的落地**:
- 规划中的“情景推演室”，利用现有 MA 信号引擎进行风险演练。
- “风险沙盒”概念，通过模拟大盘回调或板块转弱，预判自选股的风险暴露。
- 强调其“实验室”属性，专注于提升用户的复盘与预判能力。
