# A股智研台 UI 技术路线说明

## 1. 当前阶段

当前 A股智研台仍处于 **CLI + 数据管线 + Markdown/CSV 输出** 阶段。本项目尚未开发 UI 代码，所有分析结果目前通过终端、本地 CSV 文件和 Markdown 日报进行展示。

## 2. 未来 UI 主线路线

为了实现“先进、漂亮、现代化”的产品愿景，并提供极佳的 macOS 桌面体验，我们选定以下技术栈作为未来 UI 的主控主线：

- **框架**: **Tauri** (轻量级、安全、高性能的跨平台桌面应用工具链)
- **前端**: **React + TypeScript + Tailwind CSS** (构建高度可交互、现代化且易于维护的 UI)
- **后端/Sidecar**: **Python** (继续承担数据采集、信号分析、日报生成及未来 AI 投研逻辑)
- **分发**: 优先支持 macOS (** .app / .dmg **)，后续兼容 Windows。

### 为什么不选择其他方案？

- **为什么不优先 PySide6?**
  - PySide6 风格更偏向传统工程和工业软件。
  - 难以快速实现现代化、高颜值的互联网金融终端感。
- **为什么不优先 Flet?**
  - Flet 适合快速原型开发。
  - 在构建极高颜值的专业级金融终端时，表现力和组件生态相对受限。
- **为什么不直接 SwiftUI?**
  - 虽然 macOS 原生体验最强，但与现有 Python 数据层衔接成本较高，且对未来 Windows 兼容性支持不足。

## 3. 职责分工

### 前端 (Tauri/React) 负责：
- **Dashboard**: 市场全局概览卡片。
- **可视化**: 专业的金融图表（K线、均线趋势、行业对比）。
- **交互**: 筛选、排序、搜索自选股与板块。
- **预览**: 完美的 Markdown 日报渲染展示。
- **工作区**: 多窗口、多模块的投研布局。

### 后端 (Python Sidecar) 负责：
- **数据采集**: AKShare 等数据源的高效抓取。
- **业务逻辑**: `run-daily` 任务、`doctor` 诊断。
- **分析引擎**: 指数/板块/自选股的 MA 信号及复杂策略计算。
- **持久化**: 维护 CSV 缓存、日报文件生成。
- **AI 引擎**: 接入 LLM 进行投研摘要生成（未来规划）。

## 4. 产品气质关键词

- **macOS Native**: 深度适配 Mac 窗口管理与视觉规范。
- **高级金融终端**: 类似 Bloomberg、TradingView 或主流美股终端的清爽感。
- **AI-First**: 界面设计预留充足的 AI 交互与报告摘要展示区域。
- **信息密度适中**: 既保证专业数据的展示，又通过留白和排版避免视觉压迫。
