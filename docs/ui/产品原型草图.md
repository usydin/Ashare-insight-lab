## 2. 视觉设计规范

### 2.1 视觉气质
- **高级灰/清爽感**: 背景采用浅灰（亮色模式）或深邃蓝灰（暗色模式）。
- **macOS Native**: 窗口圆角、侧边栏磨砂感 (Translucent Side Bar)。
- **金融终端感**: 字体优先选择等宽或专业非衬线体，保持数字对齐。

### 2.2 状态标签颜色
为保持界面高级感，颜色使用需克制：
- **Positive (看多)**: 柔和的翠绿或金融蓝，不使用过于刺眼的亮绿。
- **Negative (看空)**: 柔和的橙红或暗红。
- **Neutral (中性)**: 浅灰色。
- **Warning/Stale (预警)**: 琥珀色。

### 2.3 交互体验
- **悬浮态**: 鼠标悬停在表格行或卡片上时，背景轻微高亮。
- **响应式**: 支持侧边栏折叠以腾出更多数据展示区域。
- **一键运行**: 顶部状态栏提供一个明显的“刷新”按钮，触发 Python 侧的 `run-daily`。
