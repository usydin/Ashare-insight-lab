# 数据安全与账号隔离

## 数据分类

建议将数据分为三类：

1. 代码与文档
2. 本地测试数据
3. 正式运行数据与敏感凭据

## 当前规则

- 代码与文档可以进入 Git 仓库
- 本地测试数据默认不提交
- 正式运行数据不得提交
- token、API key、账号信息不得提交

## 账号隔离原则

- 开发账号仅用于开发、调试、文档维护
- 部署机账号仅用于运行服务和保存正式记录
- 不在开发机长期保留部署机敏感信息

## 建议做法

- 使用 `.env` 保存本地敏感配置
- 使用 `.env.example` 只保留字段名，不写真实值
- 未来部署机单独维护运行时凭据
- 定期检查 `.gitignore` 是否覆盖数据库、日志和数据目录
